# Dictionaries

Wordlists shipped inside the Xcrack binary. Each is embedded at build time
(`//go:embed`) by a source file in the parent `candidates` package, so the
corresponding `xcrack` flag works anywhere with no external file to locate.

| File | Flag / API | Generated by | Notes |
| --- | --- | --- | --- |
| `swedish.txt` | `--swedish` / `candidates.Swedish()` | `../gen_swedish.go` | ~31k Swedish-targeted entries (common words, names, places, clubs, holidays + typical mutations), ordered most-probable-first. |

## Adding a dictionary

1. Drop the `.txt` file here (one candidate per line, UTF-8, ordered
   most-probable-first; keep it compact — it ships in every binary).
2. Add an embed + `Source` constructor in the `candidates` package
   (mirror `../swedish.go`), embedding `dictionaries/<name>.txt`.
3. If it is generated, add a `//go:build ignore` generator next to
   `../gen_swedish.go` and record the regenerate command in its header.
4. Wire the CLI flag in `xcrack/cmd/xcrack` and note it in `docs/USAGE.md`.

Large general-purpose corpora (rockyou and friends) are **not** shipped here —
pass those with `-w FILE`. These embedded lists are the compact, high-yield,
language/locale-specific sets that benefit from always being available.
